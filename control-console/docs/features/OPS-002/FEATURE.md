# OPS-002: Pilot durable feature interview workflow

Status: interviewing
Owner: shared
Scope: Nulane Work Control interview, repository documentation, and adapter consistency only

## Outcome

An operator can initialize a feature once, answer one consequential question at a time from the CLI or private adapters, and see every answer preserved in PostgreSQL and the repository feature files before implementation starts.

## Current behavior

Before this build, the control-console prototype displayed mock operational data, had no authoritative task database, and provided no installed shell command that Codex could use to record a feature interview, progress, blockers, verification, or completion.

## Desired behavior

Pending interview.
