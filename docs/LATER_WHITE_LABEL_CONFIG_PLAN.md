# Later White-Label Config Plan

This quick path centralizes enough branding to ship the Inspection-Trac portal for review.

Later work should replace the quick preset with:

- Tenant config schema for labels, logos, colors, support contacts, feature flags, and legal/footer ownership.
- Build targets for each branded portal.
- Per-customer assets and config files.
- GitLab CI build matrix for branded static exports.
- Vercel project-per-target deployment.

Do not use the quick path as a reason to scatter customer strings through stable portal code.
